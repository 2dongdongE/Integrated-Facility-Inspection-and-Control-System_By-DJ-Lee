PC 옮기고 작업 

먼저 VS code에서 파이썬 라이브러리 설치 

1. 터미널에 패키지 설치 명령어 입력: pip install streamlit pandas pillow qrcode

2. 앱 다시 실행하기: python -m streamlit run app.py

클라우드 작동되게 하려면 

1. https://github.com/ 접속해서 app.py 제대로 올라가 있는지 확인
2. https://share.streamlit.io/ 접속해서 Streamlit Community Cloud 서버 github 연결
3. https://dashboard.uptimerobot.com 싸이트 설정해서 UptimeRobot이 자동으로 스트림릿 앱에 접속 신호를 보내어 슬립 방지
